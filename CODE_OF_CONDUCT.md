# Code of Conduct

## The short version

Be decent. Assume the other person is trying to help.

## The longer version

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

Behaviour that will not be tolerated includes harassment, personal attacks, publishing
someone's private information, and sustained disruption of discussion. Technical
disagreement is welcome and is not any of those things.

Maintainers may edit, remove, or reject contributions that do not follow this document,
and will explain why when they do.

## Reporting

Report unacceptable behaviour by opening a
[private security advisory](https://github.com/mbrummerstedt/claude-top/security/advisories/new),
which is the private channel this repository has. Reports are handled confidentially.
